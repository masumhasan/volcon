# volcon
Volume Control Browser extensions

Volcon raises or fades HTML5 audio and video on the current tab to a selected volume.

## Use

Load the repository as an unpacked extension in `chrome://extensions`, open a page containing media, then use the Volcon popup:

- **Raise** raises quieter media to the target without lowering media already louder than the target.
- **Fade** moves media to the exact target over the selected duration.
